💡 Hallazgos clave

  • --cache-type-k q8_0 --cache-type-v q8_0 es la config más rápida del benchmark (avg 78.88s, 34.73 tok/s)
  • -ngl 28 es contraproducente para Qwen3.6-35B-A3B MoE — necesita más GPU coverage
  • --n-cpu-moe 8 con contexto medio (65536) es más consistente que valores altos (16-20)
  • --ubatch-size 64 vs 128: diferencia mínima en throughput (~1 tok/s), ubatch64 mejor en prompt eval
  • Para respuestas largas (>3000 tokens): el gap entre configs se amplifica — cache-k8 61-107s vs moe-20 153-187s (+100%)
  • max_tokens debe ser >= 4096 para prompts que generan código extenso
